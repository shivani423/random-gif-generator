# Random GIF Generator 🎉

A React app that generates random GIFs using the Giphy API.

## 🚀 Features
- Generate random GIF
- Search GIF by tag
- Loading spinner
- Responsive UI

## 🛠 Tech Stack
- React
- Tailwind CSS
- Giphy API

## ⚙️ Setup Instructions
1. Clone repo
git clone https://github.com/shivani423/random-gif-generator.git

2. Install dependencies
npm install

3. Create .env file
REACT_APP_GIPHY_API_KEY=your_api_key

4. Run project
npm start
